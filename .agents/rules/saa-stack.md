# Sistema de Apoio e Acessibilidade — contexto do projeto

- **Stack:** Node.js, Express, EJS, JavaScript, CSS, HTML e MongoDB.
- **Escopo do produto:** plataforma web voltada para apoio acadêmico e acessibilidade, com foco em inclusão, organização de informações e melhor experiência para usuários.
- **Idioma da interface:** mensagens visíveis ao usuário em **português** (Brasil).
<!-- - **Arquitetura:** seguir padrão MVC quando possível, separando rotas, controllers, serviços e views. -->
- **Banco de dados:** MongoDB para armazenamento de usuários, conteúdos e recursos do sistema.
- **Autenticação:** login e cadastro de usuários com armazenamento seguro de senhas.
- **Acessibilidade:** priorizar boas práticas de acessibilidade:
  - uso de HTML semântico;
  - contraste adequado;
  - navegação por teclado;
  - compatibilidade com leitores de tela;
  - labels e descrições acessíveis;
  - responsividade para dispositivos móveis.
- **Frontend:** utilizar EJS para renderização das páginas e manter arquivos estáticos organizados em `assets/`.
- **Estilo do código:** manter código organizado, legível e modularizado, evitando duplicação.
- **Objetivo acadêmico:** o projeto serve como prática de desenvolvimento full stack e aplicação de conceitos de acessibilidade e boas práticas web.

Não introduzir frameworks frontend, ORMs ou bibliotecas fora do escopo do projeto sem necessidade ou solicitação explícita.
